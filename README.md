# Restaurant Management System

## Description
A Restaurant Management System developed using PHP, MySQL, HTML, CSS, Bootstrap, and JavaScript.

## Features
- User Registration & Login
- Customer Dashboard
- Menu Management
- Cart & Order System
- Table Reservation
- Order History
- Admin Dashboard
- Staff Dashboard
- REST APIs

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript
- XAMPP

## Database

The project uses MySQL as the backend database.

### Database Files

- `restaurant_db.sql` – Database structure and sample data.
- `database_schema.png` – Entity Relationship (ER) Diagram of the database.

## Installation
1. Copy the project folder into `htdocs`.
2. Import `restaurant_db.sql` into phpMyAdmin.
3. Start Apache and MySQL in XAMPP.
4. Open `http://localhost/Restaurant-Management-System`.

## Project Structure
- `admin/` – Admin modules
- `customer/` – Customer modules
- `staff/` – Staff modules
- `api/` – REST API endpoints
- `includes/` – Database connection and common files
- `uploads/` – Uploaded menu images
